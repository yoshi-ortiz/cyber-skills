# Graphic design fundamentals

Graphic design fundamentals are teachable formal relationships, not a style
pack and not evidence of what a particular user likes. RISD's curriculum names
form, image, color, typography, visual systems, history, and social context as
core areas of study.[^risd-graphic-design-bfa]

## Checkable constraints

- **Legibility:** test the final foreground/background pair. WCAG 2.2 requires
  at least 4.5:1 for normal text, 3:1 for large text, and 3:1 for meaningful
  non-text UI components and graphics.[^wcag-22]
- **Measure:** declare line length. The skill uses 45–75 characters as a
  readable default heuristic, consistent with university accessibility
  guidance; it is not a WCAG conformance threshold.[^arizona-accessible-branding]
- **Grid:** declare the organizing system and the rule for breaking it.
- **Grouping:** name the visible relation—proximity, similarity, continuity,
  closure, or figure-ground—rather than claiming that items “feel connected.”
- **Hierarchy:** identify primary, secondary, and tertiary attention at the
  actual output size.

## Directed principles

Point, line, shape, form, space, texture, value, color, typography, and image
register are vocabulary for describing evidence. Their meaning depends on
relationships in the artifact. A diagonal is not automatically dynamic, and a
serif is not automatically authoritative; inspect what surrounds it, what it
contrasts with, and what the ranked corpus supports.

Use these principles to make a direction explicit. Use deterministic checks to
block illegible output. Neither substitutes for user Preference Evidence.
