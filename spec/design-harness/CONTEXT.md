# Design harness

`graphics-manifest.json` is the tool manifest and `scene-spec.json` is geometry
truth; every other file here is derived from them or appended by a run.
`corpus.json` is regenerated by `observe`, so edit the moodboard folder, not the
index of it.

`handoff-2026-08-30.md` is the session record that started the graphics loop.
It is history, kept for its corpus stances; the loop's current contract lives in
`aesthetic/references/text-to-graphics.md`.
