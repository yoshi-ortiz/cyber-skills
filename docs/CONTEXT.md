# Docs

Repo-Dev Context, and fog on every channel. A contract here says what a skill
must do; the skill says how, in its own directory, where an agent running it
will actually find it.

No `max_file_bytes`. Nothing here is loaded by a run, so nothing here costs a
session anything. The constraint that matters is admission.
