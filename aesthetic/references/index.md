# Aesthetic reference index

This is the self-contained knowledge map for the skill. Operational concepts
describe how the harness behaves. Golden Rule concepts carry independent
academic, standards, or institutional evidence. No concept depends on a
personal knowledge-vault path.

## Provenance verification

Run `python3 scripts/verify_references.py` for deterministic offline structure,
links, citations, academic-role, and cached-receipt checks. Use `--online` for a
bounded refresh of source reachability. A passing receipt means the named
resource was reachable; it does not certify every claim as true.
