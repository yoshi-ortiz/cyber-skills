# Rejected shots

Corpus tagged `avoid` and `near-hit`. A round that only keeps its winners
cannot tell a later round what it already tried, so the next proposal
rediscovers the same dead end and the designer says "I already said no" a
second time.

Named for what the designer called them. The vocabulary is theirs.
