# Scripts

Standard library only, `--help` on every entry point, a `test_*.py` beside each
module that runs under `python3 -m unittest`.

`okf.py` deliberately stops short of distillation. A script that condensed a
page would be writing the one part of a knowledge file that has to be produced
by something that understood the source, and it would produce a file that looks
cited without anyone having read it.
