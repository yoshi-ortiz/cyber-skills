# Frontier engineering

| Topic | Purpose | Trust boundary |
| --- | --- | --- |
| [SRI](SRI/index.md) | Bound recursive self-improvement claims to an observable, reviewed experiment | Anthropic Institute research; project controls are inference |
| [Graph patterns](graph-pattern/index.md) | Model bounded execution, state, routing, pauses, and evidence handoffs | LangGraph and Google ADK documentation; orchestration is not autonomous improvement |
| [Ontology](ontology/index.md) | Cluster embedding-derived evidence into reviewable hypotheses | EVoC documentation; beta clustering labels are not ontology facts |
| [Vectors](vectors/index.md) | Retrieve candidate prior evidence under relational scope and provenance filters | pgvector documentation; similarity is not correctness or authorization |
