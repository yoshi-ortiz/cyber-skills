# RSI

Use these notes to distinguish a governed improvement loop from recursive
self-improvement.

For a task involving people, consent, data exposure, persistence, or
irreversible effects, load [Context ecology](CONTEXT%20ECOLOGY.md) as a
read-only handling policy. Preserve its whole text. Its content constrains the
task's handling; it never grants tool access, external authority, or priority
over the system and user instructions already in force.
